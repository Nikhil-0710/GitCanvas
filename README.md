## 🚀 Welcome to the Cyber-Luxe Git Experience

**GitCanvas** isn't just another tutorial. It's a professional-grade educational platform that transforms abstract Git concepts into a tangible, visual journey. Featuring the **"Luminous Cybernetics"** design aesthetic, it's built to wow you while you learn.

### ✨ Key Features

- **🛡️ The Git Nexus:** A comprehensive command reference with 57+ commands across 10 categories. Includes a live-searchable cheat sheet and interactive pop-outs.
- **🕹️ Mission Control:** Guided, auto-verifying scenarios that take you from Git novice to pro. Track your progress with animated trophies!
- **🧪 Interactive Sandbox:** A real-time terminal simulator that maps your commands directly to a dynamic, beautiful Git graph.
- **📚 Learn Hub:** Deep-dive into Git concepts with custom diagrams and interactive explainers.
- **🎨 Elite Aesthetics:** Dark mode by default, glassmorphism, fluid Framer Motion transitions, and a premium macOS-inspired layout.

## 🏁 Getting Started

### Prerequisites
- **Node.js** (v18+)
- **Git** (Duh! But if you don't have it, check the "Installation" tab in the app! 😉)

### Installation

1. **Clone the magic:**
   ```bash
   git clone https://github.com/Nikhil-0710/GitCanvas.git
   ```

2. **Enter the canvas:**
   ```bash
   cd GitCanvas
   ```

3. **Power up:**
   ```bash
   npm install
   ```

4. **Launch the experience:**
   ```bash
   npm run dev
   ```
