# 🎨 GitCanvas

**GitCanvas** is a high-fidelity, interactive Git simulator and educational hub designed to help developers master version control with visual precision and a premium macOS-inspired aesthetic.

![GitCanvas Banner](https://images.unsplash.com/photo-1618401471353-b98afee0b2eb?q=80&w=2088&auto=format&fit=crop)

## ✨ Features

- **🚀 Git Nexus (Information Hub):** Explore Git concepts through interactive 3D flip cards with rotating gradient effects.
- **💻 Interactive Sandbox:** A real-time terminal simulator that maps commands directly to a visual graph.
- **🌿 Visual Git Graph:** Built with React Flow to visualize branch structures, commits, and head pointers in real-time.
- **🎨 Premium UI/UX:** macOS-inspired window controls, glassmorphism, dynamic theme variables, and smooth Framer Motion animations.
- **📚 Interactive Tutorials:** Built-in guides for Git basics, branching, merging, and environment setup for macOS & Windows.

## 🛠️ Tech Stack

- **Core:** React 18, Vite
- **Visualizer:** React Flow
- **Styling:** Vanilla CSS + Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **State Management:** Zustand

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Nikhil-0710/GitCanvas.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd GitCanvas
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

## 🏗️ Building for Production

To create an optimized production build:

```bash
npm run build
```

The output will be generated in the `dist` folder.
